COSMICROW — SKÁLAVÍK LANDMARKS V3

Open index.html with a local HTTP server or upload this folder to the story-test branch.
Use SKÁLAVÍK LANDMARKS button at bottom left to toggle scene. Rowing distance displayed in #hDist drives the house crossing the foreground; the mountain is a fixed backdrop.

The neon house is a hand-traced 2.5D illustration based on the supplied real photograph, not an exact architectural scan. The GLB reference model is included but not yet rendered by the game engine. The mountain is a hand-traced silhouette based on the stylized reference image.

Main game code and PM5 computations have not been changed. Not browser- or PM5-hardware-tested. Do not merge into main without verification.
